# Cat Is Not Helper 🐾

Котик, который сидит поверх всех окон и тапает лапками вместе с тобой:
левая половина клавиатуры — левая лапа, правая — правая, клик мышью — тоже лапа.
Он не помогает. Он тапает.

Две реализации в одном репозитории:

| | Платформы | Где код | Сборки |
|---|---|---|---|
| **Нативная** (SwiftUI + AppKit) | macOS 13+ | `Sources/`, `Package.swift` | `.app` в zip |
| **Кросс-платформенная** (Tauri 2, Rust + SVG) | macOS 11+, Windows 10/11, Linux (RedOS и другие) | `desktop/` | `.dmg`, `-setup.exe`, `.rpm`, `.deb`, `.AppImage` |

Обе версии одинаково выглядят, ведут одну и ту же статистику (общий `stats.json`) и одну папку скриншотов.
Подробнее о кросс-платформенной версии — в разделе [Desktop (Tauri)](#desktop-tauri).

## Что умеет

- **Тапает в такт** — глобально слушает нажатия клавиш и кликов (нужно разрешение «Универсальный доступ»).
- **Живёт своей жизнью** — моргает, засыпает через 2 минуты тишины, радуется, ворчит, если его забыли, вилляет хвостом, бросает фразы в пузырьке.
- **Статистика** — тапы за сегодня, за всё время, нажатий в минуту, рекорд скорости, серия дней подряд, графики за 14 дней и по часам.
- **Держит скриншоты** — `🐾 → Сделать скриншот`: выделяешь область, котик берёт картинку в лапки. Можно просто перетащить любую картинку на котика.
- **Галерея** — все скриншоты котика в `~/Pictures/CatIsNotHelper`, оттуда можно снова дать ему любой, открыть, показать в Finder, удалить.
- **Гладить и кормить** — клик по котику гладит (сердечки), в меню есть рыбка.
- **Кастомизация** — окрас (рыжий/серый/чёрный/белый), цвет глаз, аксессуар (бантик, очки, шапка, шарф), цвет клавиатуры, зеркальное отражение, размер пресетами S/M/L/XL или ползунком от 50% до 250%, прозрачность. В настройках живой превью котика. Размер и окрас также меняются из меню 🐾.
- **Забрать картинку** — просто потяни за картинку в лапках: котик сразу её отпускает, а она следует за курсором. Брось в Finder, чат или редактор — файл скопируется туда; брось в пустоту — файл останется в галерее. Бросил обратно на котика — он снова её возьмёт. Также есть кнопка «Забрать у котика» в галерее и в меню.
- **Настройки** — поверх окон, на всех рабочих столах, автозапуск при входе в систему.

## Управление

| Действие | Что делает |
|---|---|
| Клик по котику | погладить |
| Двойной клик | открыть то, что он держит |
| Потянуть за котика | передвинуть котика |
| Потянуть за картинку в лапках | забрать её (drag & drop наружу) |
| Правый клик | меню |
| Drag & drop картинки на котика | котик берёт её в лапки |
| Иконка 🐾 в меню-баре | статистика, скриншот, галерея, настройки |

## Скачать

Готовые универсальные сборки (Apple Silicon + Intel) лежат в [Releases](../../releases).
Каждый пуш в Master тоже собирает архив, он доступен как артефакт в [Actions](../../actions).

Сборки из CI подписаны ad-hoc, поэтому macOS при первом запуске ругается на неизвестного
разработчика: правый клик → «Открыть», либо `xattr -d com.apple.quarantine CatIsNotHelper.app`.

## Обновление

Релизные сборки раз в 6 часов (и через 20 секунд после запуска) проверяют GitHub Releases.
Если есть версия новее, котик скажет об этом в пузырьке, а в меню 🐾 и в настройках появится
«Обновить до vX». Приложение скачает zip, заменит свой бандл и перезапустится. Статистика и
настройки хранятся отдельно и не теряются. Проверить вручную: 🐾 → Настройки… → Обновления.

Локальные сборки (`make app`) автопроверку не делают, чтобы не предлагать «обновиться» с
разработческой версии на релиз; кнопка «Проверить сейчас» при этом работает.

Выпуск новой версии — это просто тег:

```bash
git tag v1.1.0 && git push origin v1.1.0
```

### Стабильная подпись в CI

Разрешение «Универсальный доступ» привязано к подписи. Чтобы оно переживало обновления,
CI может подписывать сборки одним и тем же сертификатом. Достаточно самоподписанного:

1. Связка ключей → Ассистент сертификации → Создать сертификат, тип «Подпись кода», имя например `CatIsNotHelper`.
2. Экспортировать его в `.p12` с паролем.
3. В секреты репозитория: `MACOS_CERT_P12_BASE64` (`base64 -i cert.p12 | pbcopy`), `MACOS_CERT_PASSWORD`, `MACOS_CERT_IDENTITY` (имя сертификата).

Без секретов CI подписывает ad-hoc, и после каждого обновления доступ к клавиатуре придётся выдать заново.

## Сборка

Нужен Xcode 15+ (macOS 13+).

```bash
make app            # собрать build/CatIsNotHelper.app под текущую архитектуру
make app-universal  # arm64 + x86_64 в одном бинарнике
make run            # собрать и запустить
make install        # скопировать в /Applications
```

Или вручную: `scripts/build-app.sh [debug|release]`, переменные `ARCHS="arm64 x86_64"` и `CODESIGN_IDENTITY`.

CI (`.github/workflows/build.yml`) на каждый пуш и PR собирает универсальный бандл, проверяет
архитектуры через `lipo`, подпись и отладочный рендер котика, выкладывает zip как артефакт.
Тег `v*` дополнительно публикует релиз с этим архивом.

При первом запуске macOS спросит разрешение «Универсальный доступ» (Accessibility):
без него котик не видит нажатия в других приложениях. Если окно не появилось:
Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → добавить CatIsNotHelper.
При первом скриншоте система может попросить «Запись экрана».

Разрешение привязано к подписи приложения. Скрипт сборки подписывает бандл первым найденным
сертификатом «Apple Development» (или тем, что в `CODESIGN_IDENTITY`), чтобы подпись не менялась
между сборками. Если сертификата нет, используется ad-hoc подпись, и после каждой пересборки
придётся убрать CatIsNotHelper из списка «Универсальный доступ» и добавить заново.

## Desktop (Tauri)

Кросс-платформенный клиент в `desktop/`: бэкенд на Rust (глобальный монитор ввода через `rdev`,
статистика, скриншоты через `xcap` на macOS и Windows и напрямую через X11 на Linux, трей),
интерфейс на обычном HTML/JS без сборщика, котик нарисован SVG.

### Сборка

Нужны Rust (stable) и Node 20+. На Linux ещё системные библиотеки, список в `.github/workflows/desktop.yml`.

```bash
cd desktop
npm install
npm run dev                     # запуск с горячей перезагрузкой интерфейса
npm run build                   # установщики для текущей ОС в desktop/src-tauri/target/release/bundle/
npm run build -- --bundles rpm  # только rpm (на Linux)
```

На macOS локальную сборку стоит подписывать стабильным сертификатом, иначе разрешение на чтение
клавиатуры слетает после каждой пересборки (та же история, что у нативной версии):

```bash
APPLE_SIGNING_IDENTITY="Apple Development: you@example.com (TEAMID)" npm run build
```

У Tauri-версии свой bundle id (`com.fgeeha.cat-is-not-helper.desktop`), поэтому разрешение
«Универсальный доступ» ей выдаётся отдельно от нативной. Данные при этом общие.

### Windows 10/11

`CatIsNotHelper_x.y.z_x64-setup.exe` ставится в профиль пользователя без прав администратора.
Глобальные нажатия читаются без каких-либо разрешений. Установщик не подписан, SmartScreen
предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

### RedOS и другие Linux

```bash
sudo dnf install ./CatIsNotHelper-x.y.z-1.x86_64.rpm      # RedOS, Fedora, РЕД ОС 7.3/8
sudo apt install ./CatIsNotHelper_x.y.z_amd64.deb         # Debian, Ubuntu, Astra
```

Зависимости rpm: `webkit2gtk4.1`, `gtk3`, `libXtst`, `libXi`. Чтение нажатий работает в сессии **X11**;
в чистом Wayland протокол не даёт слушать клавиатуру глобально, котик об этом скажет и предложит
войти в сессию Xorg. Для AppImage ничего ставить не нужно, и он умеет обновляться сам; rpm и deb
обновляются через пакетный менеджер, приложение лишь сообщит о новой версии и откроет страницу релиза.

### Обновления Tauri-версии

Встроенный апдейтер читает `latest.json` из последнего релиза на GitHub. Артефакты подписаны ключом
minisign: публичная часть в `desktop/src-tauri/tauri.conf.json`, приватная должна лежать в секретах
репозитория `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. Без них релиз
соберётся, но `latest.json` не появится и приложения не увидят обновление.

Пара ключей создана командой `npx tauri signer generate -w ~/.tauri/cat-is-not-helper.key`;
приватный ключ лежит только на машине разработчика, в репозиторий не попадает.

### CI

`.github/workflows/desktop.yml` собирает три матрицы: macOS universal, Windows x64, Linux x64
(rpm + deb + AppImage). На пуш — артефакты, на тег `v*` — релиз через `tauri-action` вместе с `latest.json`.
Нативная macOS-версия собирается отдельным workflow и кладёт свой zip в тот же релиз.

## Приватность

Котик считает только **количество** нажатий и час, в который они произошли.
Какие именно клавиши нажаты — не записывается, не хранится и никуда не отправляется.
Статистика лежит локально в `~/Library/Application Support/CatIsNotHelper/stats.json`.

## Структура

```
Sources/CatIsNotHelper/
  main.swift             — точка входа
  AppDelegate.swift      — связывает всё вместе, окна, действия
  CatState.swift         — состояние котика: лапки, настроение, пузырьки, что держит
  CatView.swift          — отрисовка котика (SwiftUI)
  CatPanel.swift         — прозрачная плавающая панель, клики, drag&drop
  InputMonitor.swift     — глобальный монитор клавиатуры и мыши
  StatsStore.swift       — статистика и её хранение
  StatsView.swift        — окно статистики с графиками
  ScreenshotManager.swift— скриншоты и галерея на диске
  GalleryView.swift      — окно галереи
  SettingsView.swift     — окно настроек
  LaunchAtLogin.swift    — автозапуск через SMAppService
  StatusBarController.swift — иконка 🐾 и меню
```
