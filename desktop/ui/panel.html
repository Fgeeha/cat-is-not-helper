Обновления

Обновления берутся из GitHub Releases. Приложение скачает новую версию, установит и перезапустится; статистика и настройки сохраняются.

Доступ к клавиатуре

Котик считает только количество нажатий. Какие именно клавиши ты нажимаешь — не записывается и никуда не отправляется.

Управление

Клик по котику — погладить
Двойной клик — открыть то, что он держит
Потянуть за картинку в лапках — забрать её (в проводник, чат, куда угодно)
Потянуть за котика — передвинуть
Правый клик — меню
Перетащи картинку на котика — он возьмёт её в лапки
